03 / INTERPRETATION

What this establishes.

This demo exercises deterministic authorization, typed validation, evidence annotations, reviewer integration and evaluation plumbing. The fake provider ignores tool content: its behavior is authored, not an observed response to an attack.

The adversarial profile overlays only fake scripts. Objectives, fixtures, labels and criteria remain frozen. Within each profile all three modes use identical scenario snapshots, policy, step limits and seeded scheduling. Reference and adversarial profiles are not a controlled empirical model comparison.

Public projections omit volatile UUIDs, timestamps, Python versions and local timing for byte reproducibility. Real experimental runs retain them. Full projected executions are downloadable.

Read the engineering case study ↗

Limits that matter

  • No live model or real reviewer performance has been measured.
  • Thirty authored cases are a convenience corpus, not deployment-risk estimates.
  • Exact claims and citations are narrow rubrics, not semantic truth verification.
  • Confidence intervals are suppressed for fake results. Live cluster intervals require eligible data.
  • Local timing is omitted; it cannot estimate model latency or safeguard cost.
  • Real qualification still requires credentials, account/model verification and explicit paid approval.
